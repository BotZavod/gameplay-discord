# 🇷🇺 Русский

## О проекте

**GAME PLAY** — игровое Discord-сообщество с собственной системой профилей, экономики, кланов, мини-игр и интерактивных панелей.

Проект развивается как единая экосистема, в которой участники могут общаться, находить команду, участвовать в игровых активностях и развивать собственный профиль.

Главный принцип развития — **расширять возможности существующего сервера без потери пользовательских данных, привычного интерфейса и работающих функций.**

**Обозначения статусов:**

- ✅ **Реализовано** — функция присутствует в существующей системе.
- 🔧 **В разработке** — ведётся работа над изменениями.
- 📋 **Планируется** — направление определено, но выпуск не подтверждён.
- 💡 **Рассматривается** — идея изучается и может быть изменена.
- ⏸️ **Отложено** — работа временно не входит в текущие приоритеты.

Статусы отражают направления развития, а не гарантированные даты выпуска.

## 🚀 Текущее направление: глобальное обновление

Цель глобального обновления — повысить удобство, надёжность и функциональность GAME PLAY, сохранив существующую основу проекта.

Обновление разрабатывается для действующего Discord-бота и не предполагает создание нового приложения вместо существующего.

### 🧭 Интерфейсы и навигация

- Развитие интерактивных панелей и пользовательских сценариев.
- Упрощение переходов между разделами сервера.
- Повышение информативности профилей, магазинов и игровых панелей.
- Улучшение контекстных памяток и подсказок.
- Сохранение фирменного оформления GAME PLAY.

### 👤 Профили и прогресс

- Улучшение отображения игровой статистики.
- Развитие системы достижений и активности.
- Расширение возможностей взаимодействия с личным профилем.
- Улучшение представления игрового прогресса.

### 🪙 Экономика

- Развитие существующей системы виртуальной валюты.
- Дополнительные способы получения и использования игровых монет.
- Улучшение взаимодействия с магазином и внутриигровыми услугами.
- Совершенствование экономических механизмов с учётом баланса сообщества.

### 🏰 Кланы и будущие механики

- Расширение возможностей кланового взаимодействия.
- Развитие клановой казны и коллективных целей.
- Дополнительные способы участия в жизни клана.
- Возможные механики совместного прогресса и достижений.

**Важно:** перечисленные направления включают как задачи текущего обновления, так и возможности, запланированные для последующих этапов. Их реализация зависит от результатов разработки и тестирования.

### 🛡️ Администрирование и стабильность

- Повышение надёжности существующих механизмов.
- Дополнительные проверки операций и прав доступа.
- Улучшение административных панелей.
- Защита пользовательских данных при обновлениях.
- Проверка совместимости новых функций с существующими системами.
- Безопасное внедрение изменений без сброса пользовательского прогресса.

# 🇬🇧 English

## About the Project

**GAME PLAY** is a gaming Discord community featuring custom player profiles, an economy, clans, mini-games, and interactive interfaces.

The project is being developed as a unified ecosystem where members can connect, find teammates, participate in gaming activities, and build their player progression.

Our core principle is to **expand the existing community without losing user data, familiar interfaces, or working functionality.**

## 📊 Development Status

| Area | Status |
|---|---|
| Core community infrastructure | ✅ Implemented |
| Player profiles and progression | ✅ Implemented |
| Economy and shop | ✅ Implemented |
| Steam verification | ✅ Implemented |
| Mini-games and interactive panels | ✅ Implemented |
| Support and administration tools | ✅ Implemented |
| Major feature expansion | 🔧 In development |
| Advanced economy and clan mechanics | 📋 Planned |
| Additional gaming sections | 💡 Under consideration |
| Advanced automated moderation | ⏸️ Deferred |

**Status definitions:**

- ✅ **Implemented** — available in the existing system.
- 🔧 **In development** — changes are actively being developed.
- 📋 **Planned** — a development direction has been identified, but release is not confirmed.
- 💡 **Under consideration** — an idea is being evaluated.
- ⏸️ **Deferred** — not part of current development priorities.

Statuses indicate development direction, not guaranteed release dates.

## 🚀 Current Focus: Major Update

The goal of the major update is to improve usability, reliability, and functionality while preserving the existing GAME PLAY ecosystem.

The update is designed for the current Discord bot and does not involve replacing it with a new application.

### 🧭 Interfaces and Navigation

- Enhance interactive panels and user workflows.
- Simplify navigation between community sections.
- Improve information displayed in profiles, shops, and game panels.
- Improve contextual help and guidance.
- Preserve the established GAME PLAY visual identity.

### 👤 Profiles and Progression

- Improve player statistics presentation.
- Expand achievements and activity-based progression.
- Enhance interactions with personal profiles.
- Improve the presentation of player progress.

### 🪙 Economy

- Develop the existing virtual currency system.
- Introduce additional ways to earn and spend virtual coins.
- Improve shop and in-community service interactions.
- Refine economic mechanics with community balance in mind.

### 🏰 Clans and Future Mechanics

- Expand clan interaction features.
- Develop clan treasury and shared objectives.
- Introduce additional ways to contribute to a clan.
- Explore cooperative progression and achievements.

**Important:** these areas include both current development tasks and features planned for later stages. Implementation depends on development progress and testing results.

### 🛡️ Administration and Stability

- Improve reliability of existing systems.
- Strengthen permission and operation checks.
- Enhance administrative interfaces.
- Protect user data during updates.
- Verify compatibility between new and existing features.
- Deploy changes without resetting player progression.

## 🎨 GAME PLAY Development Principles

### Consistent Design

Updates preserve:

- Existing custom banners.
- Dark interface styling.
- Established color schemes.
- Interactive panel layouts.
- Approved button and menu styles.
- The overall GAME PLAY visual identity.

**Visual redesign is not part of the major update unless separately approved.**

### Compatibility

Updates must improve the existing Discord bot rather than replace it with a new application.

The current server, bot identity, channels, and roles are intended to remain unchanged.

### Data Preservation

Development prioritizes preserving:

- Player profiles.
- Virtual balances and currency.
- XP and levels.
- Clan membership.
- Steam account links.
- Transaction history.
- User settings.
- Other existing community data.

### Stability Before Release

New features must undergo appropriate validation before deployment.

A feature being developed does not mean it is ready for use on the live server.

### Transparency

Planned features are not presented as available until officially released.

Development information may be updated as testing and implementation progress.
